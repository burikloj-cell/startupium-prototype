Статус сайта

Startupium сейчас является демонстрационным статическим прототипом. На сайте нет подключённого серверного аккаунта, базы пользователей, аналитической системы или формы отправки данных на сервер.

Данные демо-аккаунта

Если ты используешь форму регистрации, имя, адрес электронной почты, случайная соль и хеш пароля сохраняются в локальном хранилище браузера. Проверка пароля выполняется на устройстве с помощью Web Crypto API (PBKDF2/SHA-256). Данные не синхронизируются между устройствами и могут быть удалены при очистке данных сайта.

Не используй реальные пароли

Демо-форма предназначена только для проверки интерфейса. Не вводи пароль, который используешь в почте, социальных сетях, банке или других сервисах. Не указывай чувствительную или чужую персональную информацию.

Обращения и удаление данных

Поскольку аккаунты существуют только в браузере, удалить демо-данные можно через настройки хранения данных сайта в браузере. После подключения серверной регистрации этот документ необходимо заменить полноценной политикой обработки персональных данных с контактами оператора, целями, основаниями, сроками хранения и порядком реализации прав пользователей.

Этот текст описывает текущий технический прототип и не является юридическим заключением или готовой политикой для публичного сервиса.
