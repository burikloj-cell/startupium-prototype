# Startupium

Статический демонстрационный прототип платформы для поиска команды и совместной работы над проектами.

## Возможности прототипа

- Главная страница и разделы проектов, специалистов и информации о платформе.
- Адаптивная тёмная тема с glassmorphism, плавными переходами и поддержкой `prefers-reduced-motion`.
- Демо-регистрация и вход в браузере.
- Информационные страницы о конфиденциальности и условиях использования.
- Страница 404 и автоматическая проверка локальных ссылок.

## Локальный запуск

Открой проект через локальный HTTP-сервер. Для Web Crypto API предпочтителен HTTPS или localhost.

```bash
python -m http.server 8000
```

Перейди на http://localhost:8000.

## Важное ограничение авторизации

Регистрация не создаёт настоящую учётную запись. Демо-данные хранятся в `localStorage` конкретного браузера, а состояние входа — в `sessionStorage`. Данные не синхронизируются между устройствами и могут быть удалены очисткой хранилища сайта.

Пароль обрабатывается в браузере с помощью PBKDF2/SHA-256 и случайной соли. Это демонстрация клиентского сценария, а не production-ready авторизация. Не вводи реальные или повторно используемые пароли.

Для полноценного запуска потребуются backend/API, база данных или auth-провайдер, серверная валидация, управление сессиями, защита от злоупотреблений и юридически проверенные документы.

## Проверки

```bash
node scripts/check-site.mjs
```

Проверка запускается GitHub Actions при push в `main` или рабочую ветку и при pull request в `main`.

## Публикация

Проект подготовлен как статический сайт для GitHub Pages из корня ветки `main`. Включение Pages и слияние pull request выполняются отдельно владельцем репозитория.
